# Manual de uso

## Início

1. Abra o aplicativo.
2. Configure a empresa e a logo, se necessário.
3. Selecione uma pasta local quando desejar organizar os arquivos automaticamente.
4. Crie um novo relatório.

## Novo relatório

Preencha os dados solicitados e confirme a criação.

## Novo poste

Informe a identificação do poste e inicie as fotografias.

## Primeira fotografia

A primeira fotografia do poste é utilizada como referência para travar a coordenada do pé do poste, quando a localização estiver disponível.

## Demais fotografias

Use **Mais uma foto deste poste** para registrar outras vistas ou detalhes.

## Legenda

Depois da captura, é possível inserir uma descrição breve antes de salvar a foto.

## Anotação

Abra o editor para marcar pontos importantes da imagem com ferramentas gráficas.

## Encerramento

Depois de cadastrar os postes, volte ao relatório e utilize as opções de geração.

## Segurança

Não deixe dados importantes somente no navegador. Gere o backup e guarde os arquivos exportados.
