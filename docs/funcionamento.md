# Funcionamento

## 1. Configuração

Antes do uso, podem ser configurados:

- logo;
- nome da empresa;
- endereço;
- responsável técnico.

## 2. Criação do relatório

O relatório recebe:

- nome;
- empresa;
- Nota/OS;
- município;
- equipe;
- supervisor.

## 3. Cadastro do poste

Cada poste recebe uma identificação própria.

A primeira fotografia pode ser utilizada para definir a coordenada do pé do poste.

## 4. Fotografias

Para cada poste podem ser adicionadas várias fotografias.

Cada foto pode receber uma descrição e também ser aberta no editor de anotações.

## 5. Anotações

O editor permite inserir elementos gráficos sobre a fotografia:

- seta;
- círculo;
- retângulo;
- desenho livre;
- texto;
- escala;
- medida estimada;
- desfazer;
- limpar.

## 6. Produtos finais

Após concluir o levantamento, o usuário pode gerar:

- PDF;
- KMZ;
- DXF;
- backup ZIP.
