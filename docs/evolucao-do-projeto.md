# Evolução do projeto

## Direção atual

A aplicação já reúne captura fotográfica, georreferenciamento, organização de dados e geração de arquivos.

## Próximas evoluções possíveis

### Dados
- banco remoto;
- sincronização;
- histórico;
- controle de versões.

### Gestão
- usuários;
- equipes;
- permissões;
- painel administrativo.

### Engenharia
- melhorias na representação CAD;
- modelos técnicos;
- validações de campo;
- indicadores de inspeção.

### Integrações
- APIs corporativas;
- sistemas GIS;
- sistemas de ordens de serviço;
- armazenamento em nuvem.

## Princípio

A evolução deve preservar a ideia central do projeto: reduzir trabalho manual e transformar dados coletados em campo em informação técnica organizada.
