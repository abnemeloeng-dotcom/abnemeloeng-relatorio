# Armazenamento e backup

## Armazenamento local

Os dados e fotografias são mantidos no armazenamento do navegador.

Isso permite que o levantamento permaneça disponível no próprio aparelho sem depender de um servidor.

## Pasta local

Quando suportado pelo navegador, o usuário pode escolher uma pasta e o sistema organizar o relatório em:

```text
Relatório/
├── Fotos/
├── Relatorio/
├── KMZ/
└── CAD/
```

## Backup

O projeto possui exportação de backup em ZIP.

## Recomendação operacional

Ao finalizar um relatório:

1. gerar o PDF;
2. gerar o KMZ;
3. gerar o DXF quando necessário;
4. exportar o backup;
5. guardar os arquivos em local seguro.

## Atenção

Limpar os dados do navegador pode apagar dados de relatórios que ainda não tenham sido exportados.
